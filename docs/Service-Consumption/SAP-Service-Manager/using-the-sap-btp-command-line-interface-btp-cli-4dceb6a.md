# Using the SAP BTP Command Line Interface \(btp CLI\)

Use the SAP BTP command line interface to work with the SAP Service Manager resources.



Learn how to use the client:

-   [Download and Start Using the Client](https://help.sap.com/viewer/65de2977205c403bbc107264b8eccf4b/Cloud/en-US/8a8f17f5fd334fb583438edbd831d506.html)

-   [Set the Default Command Context](https://help.sap.com/viewer/65de2977205c403bbc107264b8eccf4b/Cloud/en-US/720645a3ed3945bd8d97a670b948ac07.html)


> ### Tip:  
> All of these commands are executed for a specific subaccount. We recommend using the `btp target` command to set the default context to a subaccount. See [Set a Target for Subsequent Commands with btp target](https://help.sap.com/docs/btp/sap-business-technology-platform/set-target-for-subsequent-commands-with-btp-target).
